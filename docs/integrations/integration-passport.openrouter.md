# OpenRouter AI Gateway

## Название
OpenRouter AI Gateway

## Назначение
AI-сопоставление регуляторных требований

## Модель
openai/gpt-4o-mini

## Endpoint
https://openrouter.ai/api/v1

## Auth
Bearer token (OPENROUTER_API_KEY)

## Timeout
30s, retry: 2

## Данные
Тексты требований и документов (не PII)

## Ограничения
- Budget: $10/месяц
- Rate limits по OpenRouter

## Статус
Active
